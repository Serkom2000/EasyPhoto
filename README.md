# EasyPhoto

Локальная фотомастерская для Windows и NVIDIA: создание изображений, изменение
фотографий и работа с кистью через простой русский интерфейс. ComfyUI работает
в фоне; пользователю не нужно собирать ноды.

## Скачать и установить

Откройте [последний релиз](https://github.com/Serkom2000/EasyPhoto/releases/latest)
и скачайте **Download-EasyPhoto.cmd**. Запустите файл: он загрузит части комплекта,
проверит их контрольные суммы, соберёт и распакует архив, затем откроет установщик.
Можно заранее скачать все пять частей `.zip.001`–`.zip.005` в ту же папку.

В комплект входят SDXL Base 1.0 и DreamShaper 8. Движок ComfyUI, отдельный Python
и библиотеки установщик скачивает сам. После установки генерация работает локально.
Для новых моделей используйте «Модели → Добавить файл модели».

GitHub ограничивает отдельный файл релиза размером менее 2 ГиБ, поэтому комплект
около 9,1 ГБ разделён на пять частей. Не пытайтесь открыть одну часть как ZIP:
используйте загрузчик, который собирает и проверяет полный архив.

## Как пользоваться

Запустите ярлык **EasyPhoto** на рабочем столе. Дождитесь «Можно создавать» —
студия откроется в браузере. Кнопка **Инструкция** в правом верхнем углу объясняет
создание фото, редактирование, кисть, модели и параметры.

Чтобы выключить программу и движок, закройте окно запуска EasyPhoto.
Закрытие вкладки браузера само по себе их не останавливает.

## Возможности и ограничения

- Создание по описанию, img2img, редактирование по маске, история и сохранение PNG.
- Выбор полных checkpoints SDXL / SD 1.5 и импорт своих `.safetensors`.
- FLUX, LoRA, автоперевод, автоматическое выделение фона и перенос личности пока
  не реализованы. Режим позы требует готовую карту OpenPose и отдельную ControlNet.
- Нужны Windows, NVIDIA и установленный системный драйвер. Скорость и качество
  зависят от модели, настроек и видеокарты; генерация не гарантирует точного
  исполнения каждой команды.

## Исходники и проверка

Код приложения находится в [EasyPhoto](EasyPhoto). Веса, runtime, личные
фотографии, история и журналы в Git не включены.

```powershell
cd EasyPhoto
python -m unittest discover -s tests -v
node --check web/app.js
```

На Windows 11 / RTX 4060 Laptop 8 ГБ проверены реальная генерация обеими моделями,
img2img, маска с сохранением пикселей вне выделения, смена моделей, установка,
закрытие и повторный запуск. [Подробный отчёт](EasyPhoto/WINDOWS_TEST_REPORT.md).

Модели и движок распространяются на условиях их авторов:
[SDXL](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0),
[DreamShaper](https://huggingface.co/Lykon/DreamShaper),
[ComfyUI](https://github.com/Comfy-Org/ComfyUI).
